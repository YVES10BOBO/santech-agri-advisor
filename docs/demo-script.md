# Demo video script (15 minutes maximum)

1. **Problem (2 min):** 35% of 3.4 million farmers reached by extension; 3 in 10 call-centre calls answered; generic advice.
2. **Live use (8 min):** in the chat, ask real questions in Kinyarwanda and English across crops and topics (pest, fertilizer, planting, post-harvest, weather, subsidies). Show a follow-up question. Show the sources each answer used.
3. **How it works (4 min):** architecture diagram, `/docs` API page, `/health` and `/version`, knowledge base, safety guardrails, logs.
4. **Roadmap (1 min):** C4IR data augmentation, voice, image pest detection, USSD/SMS, Rwanda hosting.
